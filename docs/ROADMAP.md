# ロードマップ

M0 以外は構想である。時期は約束しない。M0 の範囲を超える機能は、そのマイルストーンに入るまで実装しない。

## M0（現行の実装範囲）

ローカル PDF を開き、ページを表示・移動できる状態にする。

- PDF ファイル選択 UI
- ローカル PDF の読み込み
- 1ページ目の描画
- 前ページ / 次ページ
- 現在ページ / 総ページ数の表示
- 別 PDF の再選択
- PDF を外部へ送信しない

実装済み。仕様は [SPEC.md](SPEC.md) を正とする。

## 以降（構想）

順序の目安であり、確定した計画ではない。詳細モデルも作らない。

データ境界との対応は [DATA_MODEL.md](DATA_MODEL.md) の将来節を参照する。

| 候補 | 想定する前進 |
|---|---|
| M1 | Storyboard Data を、ページ表示を超えて扱えるようにする |
| M2 | Cut Data を人手または補助で持てるようにする |
| M3 | Cut Data から Timeline を組む |
| M4 | Timeline から Rush を出す |

M1 以降でやり得ることの例（未着手、M0 には入れない）:

- コマ枠検出
- CUT 番号認識
- OCR
- 尺入力
- タイムライン編集
- 動画再生
- MP4 出力
- AI 解析
- カメラワーク解析

## 進め方

- 実装済みの事実と構想を、README / SPEC / 本ドキュメントで分けて書く
- 次マイルストーンに入っていない機能の UI や空モジュールは作らない
- マイルストーンを進めるときは、先に SPEC と DATA_MODEL を更新してからコードを書く
