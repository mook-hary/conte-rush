プライバシーポリシー

最終更新: 2026-09-01

本サービス運営者（以下「運営者」）は、conte-rush（以下「本サービス」）におけるユーザー情報の扱いを、次のとおり定めます。

1. 取得する情報

  • ログインに使うメールアドレス
  • 認証事業者が発行するユーザー識別子（user id）
  • 有料契約に関する Stripe 上の顧客識別子、契約識別子、契約状態（支払い手段の番号そのものは本サービスでは保持しません）
  • 社内利用の有無（該当するユーザーのみ）
  • 社内招待コードを入力した場合の、その試行に関する記録（コードの平文は保存しません）

絵コンテ PDF、手描き、アップロード画像、ラッシュ、MP4、タイムシートの内容は、本サービスのサーバーへ送りません。ブラウザ内だけで処理します。

2. 利用目的

  • ログインとセッションの維持
  • 利用権の確認（社内利用または有料契約）
  • 月額料金の決済と契約管理
  • 問い合わせへの回答
  • 不正利用の防止
  • ページの再読み込みやタブ破棄のあと、同じ端末で作業を復元すること

3. 外部事業者

本サービスは次の外部サービスを使います。各事業者が、それぞれのプライバシーポリシーに従って情報を処理することがあります。

  • Supabase（認証、利用権データの保存、サーバー処理）
  • Stripe（決済、顧客と契約の管理、カスタマーポータル）
  • GitHub Pages（静的ファイルの配信。アクセスログを GitHub が処理し得ます）
  • jsDelivr（PDF.js などのライブラリ配信。制作ファイルの中身は含めません）

クレジットカード番号などの支払詳細は、Stripe の決済画面で Stripe が処理します。本サービスのデータベースには保存しません。

4. ブラウザ内の保存

ログイン状態を維持するため、認証ライブラリがブラウザのストレージへセッション情報を置くことがあります。これとは別に、ページの再読み込みやタブ破棄のあと作業を戻すため、制作データ（PDF、Panel、Cut、Timeline、Motion、手描き / アップロード画像）の一部を、ログイン中のユーザーごとに端末内の IndexedDB へ保存します。これはクラウド保存ではなく、本サービスのサーバーへ制作データを送る機能ではありません。ログアウトすると、画面上の作業は閉じますが、同じ端末の IndexedDB 上の制作データは残します。ブラウザのサイトデータ削除や別の端末では復元できません。

5. 第三者提供

法令に基づく場合を除き、ユーザーの個人情報を販売しません。決済と認証のため、上記の外部事業者へ必要な範囲で提供します。

6. 保管と削除

利用権と契約の記録は、サービス提供に必要な間、保管します。アカウント削除の機能は、現時点では提供していません。削除を希望する場合は問い合わせてください。

7. お問い合わせ

個人情報に関する問い合わせは、mook.hary@gmail.com へお願いします。
